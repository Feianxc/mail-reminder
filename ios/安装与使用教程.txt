邮件提醒助手 iOS 1.3.0 安装与使用教程

适用设备为 Windows 电脑与 iOS 16 或更高版本的 iPhone。
安装文件名为“邮件提醒助手-iOS-1.3.0-未签名.ipa”。
资料核对日期为 2026 年 11 月 15 日。

一、先了解当前版本的使用范围

当前首包在 iPhone 屏幕解锁、应用保持前台时收发提醒。切换到其他应用或锁屏后，接收会暂停，回到应用后自动重连。后台和锁屏接收功能仍需后续接入 Apple 原生推送 APNs，请按前台收发工具安排使用。

这个 IPA 需要用你自己的 Apple 账户（Apple ID）签名后安装。下面使用 Windows 上的 Sideloadly 完成，免费个人账户即可使用这条安装流程。

云端 IPA 编译、下载后的包结构与哈希核验、模拟器安装和首次启动检查已通过，状态为 pass。Windows 本机签名安装与 iPhone 真机收发验收为 not run，实际安装和收发效果仍待真机确认。

二、准备电脑与手机

1. 在电脑上保存“邮件提醒助手-iOS-1.3.0-未签名.ipa”，并准备一根支持数据传输的 USB 线。

2. 打开 https://sideloadly.io/，下载适合电脑的 Windows 版本。核对时官网展示 v0.71.0，实际安装采用官网当天提供的最新版。

3. 按 Sideloadly 官网的“Before you install”说明准备 iTunes 与 iCloud。目前官方要求使用其页面链接提供的网页安装版，并提示已有 Microsoft Store 版的用户先卸载商店版，再安装网页安装版。完成后按安装程序提示重启电脑。这些组件提供识别 iPhone 所需的 Apple 驱动与支持服务。

4. 准备你自己的 Apple 账户，并确认能完成双重认证。登录、密码和验证码均由你本人在本机操作。

5. 确认办公室电脑上的“邮件提醒助手”正在运行，托盘中的“手机绑定”窗口能显示已连接 FEIAN。绑定成功后的日常使用也需要桌面端继续运行。

三、通过 USB 签名安装

1. 解锁 iPhone，通过 USB 连接这台电脑。手机出现“信任此电脑”时点“信任”，并按提示输入手机解锁密码。若电脑上的 iTunes 也要求确认，完成确认后检查 iTunes 能识别这部手机。

2. 打开 Sideloadly，在设备列表中选择自己的 iPhone，将“邮件提醒助手-iOS-1.3.0-未签名.ipa”拖入窗口。

3. 使用 Apple ID 签名安装模式。首次安装沿用应用标识相关默认设置，在 Apple ID 栏填写自己的账户，然后点“Start”。按提示亲自完成密码输入和双重认证，等待签名与安装完成。

4. iPhone 上如出现“需要开发者模式”，打开“设置 → 隐私与安全性 → 开发者模式”，开启后按提示重启。重启解锁后，再点“启用”并输入手机密码完成确认。这个开关可能在完成首次配对或安装尝试后出现。

5. 如打开应用时出现“未受信任的开发者”，进入“设置 → 通用 → VPN 与设备管理”，打开此次签名使用的 Apple 账户对应条目，按提示信任。不同 iOS 版本的栏目名称可能略有不同。

6. 回到主屏幕打开“邮件提醒助手”。开发者模式或信任设置处理完成后，若 Sideloadly 上次提示安装未完成，再执行一次签名安装。

四、绑定办公室网段

1. 在电脑右下角托盘找到“邮件提醒助手”。右键打开“手机绑定”，点“生成手机绑定码”。窗口会显示绑定网段与八位数字码。

2. 在 iPhone 应用中点“绑定桌面端”，填入八位数字码，以及自己的手机显示名称，例如“小王的 iPhone”。名称支持中文，然后点“确认绑定”。绑定码五分钟内有效，每个码可使用一次，过期后在电脑端重新生成。

3. 绑定完成后，核对手机主界面显示的网段与你的办公室相符，例如 192.168.20.0/24。绑定码会带入相应群组，服务地址已内置。

4. 手机可使用能够访问 FEIAN 服务的 Wi-Fi 或移动网络。电脑端保持运行并连接 FEIAN，手机端保持前台，等待连接状态恢复后开始测试。

五、先做一次双向测试

1. 在手机点“联机测试”，观察电脑是否显示测试提醒，并在电脑上点“知道了”。随后查看手机“本次回执”中的“软件收到”和“已知晓”数量。

2. 在电脑上点“联机测试”，让手机保持前台，观察手机是否出现测试提醒。手机提醒展示五秒后自动关闭，也可手动关闭。需要确认已读时，点提醒上的“知道了”，或在“收到的提醒”记录中补点“知道了”。自动关闭只结束展示，人工点击才会发送知晓回执。

3. 双向测试确认后，正式使用时点击主界面写有“收到一封加急邮件，请立刻处理”的大按钮，即可向同组在线设备发送提醒。请根据发送状态与回执确认结果。

4. 日常使用期间让手机应用停留在前台。回到前台会自动重连，后台或锁屏期间的及时送达仍需后续推送功能支持。

六、名称、主题与更换绑定

打开手机右上角“设置”，可选择“高科技”或“宇宙星空”主题。

在“我的名称”中修改中文显示名称，点“保存并同步名称”，同组桌面端会收到新名称。

需要加入另一个办公室网段时，点“更换绑定”，输入目标电脑新生成的绑定码。换绑成功会解除原网段绑定。停止使用时可在设置中点“解除绑定”。

七、每七天刷新签名，以及安装新版

Apple 免费个人开发签名的描述文件自签发起七天有效。建议在到期前，将 iPhone 接回电脑，在 Sideloadly 中使用原来的 Apple 账户和应用标识重新签名、覆盖安装。签名过期后，也可通过这一步恢复打开应用。

Sideloadly 可在安装时启用自动刷新。自动刷新需要电脑开机、Sideloadly Daemon 运行，并且能通过 USB 或已配置的 Wi-Fi 同步连接到 iPhone。请定期查看刷新是否成功。

需要 Wi-Fi 刷新时，先完成 USB 配对，在 iTunes 的设备“摘要 → 选项”中开启“通过 Wi-Fi 与此 iPhone 同步”并应用，然后让电脑和手机连接同一个 Wi-Fi。无线识别异常时，可先打开 iTunes，并让手机屏幕保持点亮。

拿到后续版本 IPA 后，同样拖入 Sideloadly，沿用原来的 Apple 账户与实际使用的应用标识覆盖安装，以保留本机应用数据。更新完成后检查名称和网段，并再做一次联机测试。

八、常见问题

电脑识别不到 iPhone 时，先检查数据线、USB 接口和手机的“信任此电脑”，确认 iTunes 能识别手机，再检查是否已按 Sideloadly 官网要求安装网页安装版 iTunes 与 iCloud。

应用安装后打不开时，检查开发者模式、开发者信任与签名有效期。签名过期后，用原 Apple 账户重新签名覆盖安装。

提示免费账户安装数量达到上限时，检查手机上通过免费开发签名安装的其他应用。Apple 对每部设备同时安装的这类应用数量设有三款限制。

收不到提醒时，让手机保持前台，核对绑定网段、手机连接状态，以及电脑端的 FEIAN 连接状态，再做双向联机测试。记录发送端时间和接收端现象，便于进一步定位。

九、备选安装方式

熟悉 AltStore 的用户也可按其官方 Windows 教程安装 AltServer 与 AltStore Classic，再导入本地 IPA。免费个人签名的七天有效期同样适用，后续需要定期刷新。具体操作以文末 AltStore 官方教程为准。
